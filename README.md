# Daily 3

**Focus on three things that matter today.**

Daily 3 is a minimal iOS productivity app built around one simple rule:
choose only three important tasks for each day.

Instead of managing endless to-do lists, Daily 3 helps you decide what
actually matters today, focus on it, and see your progress over time.

## Why Daily 3?

Long to-do lists can become overwhelming. Daily 3 intentionally limits
each day to three priorities — encouraging focus over collection.

The idea is simple:

> Three priorities. One day. Clear progress.

## Status

🚧 **Widget planned next**

Foundation, the Today / MVP implementation, SwiftData persistence, the
monthly calendar, statistics, and notification implementation are complete.
Statistics include all-time totals and daily completion charts for the last
7 or 30 days. Optional morning and evening reminders have configurable
times. The next phase is adding a Home Screen widget.
